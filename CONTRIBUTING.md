# Участие в разработке

1. Используйте Node.js 22 или новее.
2. Выполните `npm ci`, затем `npm run dev`.
3. Не используйте личную базу для тестов. Все проверки работают с изолированными каталогами.
4. Перед изменением схемы создайте миграцию через `npm run db:generate` и проверьте восстановление старой копии.
5. Перед отправкой изменения выполните `npm run lint`, `npm run check`, `npm test`, `npm run build` и `npm run check:public`.
6. Для интерфейса проверьте мобильную ширину 375 px, тёмную тему, клавиатуру и `prefers-reduced-motion`.

Новые возможности должны работать без обязательного облака и не делать личные данные общедоступными. Внешние интеграции должны быть опциональными.
