# Участие в разработке

1. Используйте Node.js 22 или новее.
2. Выполните `npm ci`, затем `npm run dev`.
3. Не используйте личную базу для тестов. Все проверки работают с изолированными каталогами.
4. Перед изменением схемы создайте миграцию через `npm run db:generate` и проверьте восстановление старой копии.
5. Перед отправкой изменения выполните `npm run lint`, `npm run check`, `npm test`, `npm run build` и `npm run check:public`.
6. Для интерфейса проверьте мобильную ширину 375 px, тёмную тему, клавиатуру и `prefers-reduced-motion`.
7. Windows launcher находится в `scripts/Start-Windows.ps1`. Телефоны подключаются через браузер к серверу компьютера; отдельного нативного мобильного проекта нет.

Новые возможности должны работать без обязательного облака и не делать личные данные общедоступными. Внешние интеграции должны быть опциональными.

## Публикация изменений

Перед отправкой на GitHub убедитесь, что проверки проходят и личная база не добавлена в индекс:

```bash
npm run check:public
git status
git add .
git commit -m "Описание изменения"
git push
```

Не используйте `git add -f` для `data/`, `.env`, SQLite-баз, резервных копий, архивов, `.toolchain/` и `.release/`. Для публичной версии достаточно исходного кода; личные записи остаются только на компьютере владельца.

## Архив для скачивания

После создания git-тега соберите архив из этого тега:

```bash
npm run check:public
npm run package:release -- vX.Y.Z
```

Версия в `package.json` должна совпадать с тегом. Команда использует `git archive`, поэтому в ZIP попадают только отслеживаемые файлы, без `data/`, `.git`, `node_modules` и локальных документов. Результат:

- `.release/tochka-opory.zip` — универсальный архив для macOS и Windows;
- `.release/tochka-opory.zip.sha256` — контрольная сумма для проверки загрузки.

Перед публикацией распакуйте именно этот ZIP и повторно выполните в нём `npm run check:public`. Оба файла прикладываются к GitHub Release. Не переименовывайте ZIP: постоянная ссылка `releases/latest/download/tochka-opory.zip` автоматически направляет пользователей на архив последнего релиза.
