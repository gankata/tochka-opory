# Windows и Android

«Точка опоры» использует один локальный сервер и одну SQLite-базу. Windows и macOS могут работать самостоятельно; Android подключается к уже запущенному компьютеру и работает с той же базой. Облачная синхронизация не нужна.

| Устройство | Как запускать | Автономно без другого устройства |
| --- | --- | --- |
| macOS | `Запустить офлайн.command` | Да |
| Windows | `Запустить Windows.bat` | Да |
| Android | APK-клиент и адрес компьютера | Нет, нужен включённый компьютер с сервером |

## Windows

### Первый запуск

1. Пока есть интернет, установите [Node.js 22 или новее](https://nodejs.org/) с параметрами установщика по умолчанию.
2. Скачайте чистый проект из релиза или репозитория и распакуйте его в обычную папку, например `Документы\tochka-opory`. Не запускайте проект прямо из ZIP-архива.
3. Откройте `Запустить Windows.bat` двойным щелчком.
4. Выберите режим:
   - **1 — только Windows:** адрес `http://localhost:7100`, доступ только с этого компьютера.
   - **2 — Windows + Android:** приложение доступно обоим устройствам одновременно, в окне появится адрес для телефона.
5. При первом запуске программа выполнит `npm ci` и production-сборку. Это занимает несколько минут и требует интернета. Последующие запуски и внесение данных интернета не требуют.

Если порт 7100 занят, выбирается следующий свободный до 7199. После обновления исходного кода launcher сам заметит изменения и пересоберёт приложение. Не закрывайте окно во время работы; остановка — `Ctrl+C`.

> Не переносите чужую папку `data/` в новую установку, если хотите начать с чистой базы. Для переноса собственных записей используйте полный архив из раздела «Данные» либо целиком свою папку `data/` при остановленном сервере.

## Android

### Установка

1. Скачайте APK из GitHub Release на телефон или скопируйте его через кабель.
2. Откройте файл. Android предложит разрешить установку из выбранного источника («Файлы» или браузер) — это стандартный запрос для прямой установки.
3. Установите и откройте «Точку опоры».

APK из релиза 1.1.0 подписан **тестовым debug-ключом**, а не production-сертификатом разработчика. Он предназначен для прямой установки и личного использования, не для Google Play. В APK нет личной базы, паролей, токенов или записей.

### Подключение

1. На Windows запустите `Запустить Windows.bat` и выберите режим **2**. На macOS используйте `Запустить офлайн.command`, режим **2**.
2. Подключите компьютер и телефон к одной сети Wi-Fi.
3. В окне запуска найдите адрес вида `http://192.168.1.10:7100` и введите его в Android-приложении. Если адресов несколько, попробуйте тот, чья подсеть совпадает с адресом телефона.
4. Нажмите «Подключиться». Клиент проверит `/api/health`, затем откроет полный интерфейс.
5. Войдите с тем же локальным логином и паролем, что на компьютере. Адрес сервера сохраняется для следующего запуска.

При первом сетевом подключении Windows может показать запрос брандмауэра. Разрешайте Node.js **только в частных сетях**, не в публичных. Не пробрасывайте порт через роутер и не публикуйте локальный сервер в интернете.

### Без интернета в поездке

Android-клиенту не нужен мобильный интернет, но нужен включённый компьютер и локальная сеть между устройствами:

1. На Windows включите «Мобильный хот-спот» (раздачу Wi-Fi), даже если сам компьютер не подключён к интернету.
2. Подключите Android к этой Wi-Fi-сети.
3. Запустите сервер в режиме 2 и подключитесь по показанному адресу.

Можно использовать и домашний роутер без интернета. Режим модема на самом Android обычно не подходит для подключения этого же телефона к собственной раздаче; в такой связке удобнее раздавать Wi-Fi с Windows.

### Импорт, экспорт и навигация

- Кнопки импорта открывают системный выбор файлов.
- HTTP-скачивания выполняются системным менеджером загрузок.
- Blob-экспорты на Android 10+ сохраняются в `Загрузки/Точка опоры`; на Android 8–9 — в папку загрузок приложения.
- Кнопка «Назад» сначала возвращает по истории внутри приложения, затем — на экран подключения.
- Внешние ссылки открываются в браузере, а не получают доступ к внутреннему интерфейсу загрузок.

Если телефон потерял связь, не вводите данные повторно вслепую: восстановите Wi-Fi и проверьте, сохранилась ли последняя операция. Офлайн-очередь относится к конкретному браузеру/устройству и не является облачной синхронизацией.

## Ограничения и безопасность

- На Android нет отдельной автономной SQLite-базы. Это исключает расхождение двух копий, но означает, что без компьютера запись данных недоступна.
- Локальный HTTP не шифрует трафик. Используйте только свою сеть, не публичный Wi-Fi.
- Резервные копии создаются на компьютере, где находится база. Для защиты от отказа диска периодически копируйте их на внешний носитель.
- Тестовая подпись APK не заменяет проверенный production-сертификат. Собственный keystore для выпуска храните отдельно и никогда не добавляйте в Git.

## Если не подключается

1. Откройте `http://127.0.0.1:7100/api/health` на компьютере: должен быть JSON со `status: ok`. Если launcher выбрал другой порт, используйте его.
2. Убедитесь, что выбран режим 2, а не 1.
3. Проверьте, что телефон и компьютер в одной сети, без «изоляции клиентов»/гостевой сети.
4. Разрешите Node.js в частном профиле брандмауэра Windows или macOS.
5. Проверьте IP компьютера: он мог измениться после переподключения. Введите новый адрес в Android.
6. Не используйте VPN на одном из устройств во время локального подключения.

## Сборка Android из исходников

Нужны JDK 17, Android SDK Platform 34 и Build Tools 35.0.0:

```bash
cd android
./gradlew :app:assembleDebug
```

На Windows используйте `gradlew.bat :app:assembleDebug`. Результат появится в `android/app/build/outputs/apk/debug/app-debug.apk`. Сборка из исходников требует зависимостей Gradle/Android SDK; обычному пользователю собирать проект не нужно — достаточно готового APK из релиза.
