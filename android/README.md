# Android-клиент «Точка опоры»

Нативный Kotlin/View-клиент для подключения к локальному серверу на Windows или macOS. Он отображает полный веб-интерфейс, сохраняет адрес сервера, проверяет `/api/health`, поддерживает навигацию назад, загрузку файлов через системный диалог и сохранение HTTP/Blob-экспортов.

## Сборка

Нужны JDK 17, Android SDK Platform 34 и Build Tools 35.0.0.

```bash
./gradlew :app:assembleDebug
```

Результат: `app/build/outputs/apk/debug/app-debug.apk`. Debug-вариант подписан тестовым ключом Android и подходит для прямой установки, но не для публикации в Google Play. Для production-релиза используйте собственный защищённый keystore; не добавляйте его в Git.

HTTP разрешён намеренно: приложение рассчитано только на личную локальную сеть. Не вводите адрес публичного незашифрованного сервера. У клиента нет отдельной SQLite-базы и облачной синхронизации: все записи остаются на компьютере, где запущен сервер.

Подробная установка описана в `docs/WINDOWS-ANDROID.md`.
