# Безопасность

## Локальная модель

Приложение рассчитано на личный компьютер и доверенную локальную сеть. Production по умолчанию слушает только `127.0.0.1`. Не выставляйте HTTP-сервер напрямую в интернет. Данные SQLite локально не зашифрованы; используйте FileVault и отдельную защищённую учётную запись macOS.

Пароль хранится как scrypt-хеш с солью, сессионные токены — как SHA-256-хеши. Это не заменяет шифрование диска и не защищает от человека, уже получившего доступ к вашей сессии macOS.

## Публикация

Перед публикацией выполните `npm run check:public`. Каталог `data/`, SQLite-базы, резервные копии, журналы и файлы окружения не должны попадать в репозиторий. Не публикуйте JSON-архивы и скриншоты с личными записями.

## Сообщение об уязвимости

До настройки публичного канала безопасности создайте приватное обращение владельцу репозитория. Не прикладывайте реальную базу, пароли, токены или личные записи. Для воспроизведения используйте только вымышленные данные.
